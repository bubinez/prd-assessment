# PRD Assessment

Плагин для подготовки PRD и декомпозиции фич: уточнение требований, анализ проекта, проверка документа и формирование плана изменений.

## Установка в Codex

Добавьте репозиторий как источник плагинов:

```powershell
codex plugin marketplace add bubinez/prd-assessment
```

Затем откройте каталог плагинов в приложении ChatGPT, выберите источник PRD Assessment и установите плагин. При необходимости перезапустите приложение и начните новый чат. Доступность локальных источников зависит от клиента.

## Использование

Вызовите навык `prd-assessment` или попросите сформировать PRD и декомпозировать фичу. Пайплайн сохраняет артефакты в проекте; инструкции находятся в `plugins/prd-assessment/skills/prd-assessment/`.

При явном вызове `/prd-assessment` или `/create-prd` отдельные этапы требуют доступного механизма субагентов. Интеграция с Linear включается только по запросу и требует настроенного подключения.
